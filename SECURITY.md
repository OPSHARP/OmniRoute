# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue**. Instead:

1. Email **security@opsharp.dev** with a description of the issue
2. Include steps to reproduce, impact assessment, and any proof of concept
3. We'll acknowledge within **48 hours** and work with you on a responsible disclosure timeline

## What We Consider a Security Issue

* Remote code execution
* Authentication bypass
* Data exfiltration / privacy violations
* Insecure dependencies with known CVEs
* Injection vulnerabilities (SQLi, XSS, command injection, etc.)
* Privilege escalation

## Supported Versions

Only the latest release branch receives security updates. Please upgrade promptly.

## Scope

This policy covers the repository, its dependencies, and any associated services. It does not cover third-party integrations unless explicitly listed.
